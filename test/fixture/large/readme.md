## options

Options combine explicit `usageOptions.yml` metadata with inputs discovered from `action.yml`.

option |  | type | default | info
--- | --- | --- | --- | ---
`token` | * | `string` | `large-token` | Explicit metadata overrides the action description while inheriting required=true.
`features` |  | `string[]` | `["usage","options"]`
`fromAction` |  |  | `action-default` | This option exists only in action.yml.
`mode` |  | `fast \| safe` | `safe` | Selects a fixture mode.
`retries` |  | `number` | `3`
`verbose` |  | `boolean` | `false` | Enables verbose fixture output.

```javascript
typeof @fixture/large.default
```

Environment variables combine values from config and `envVars.yml`.

The following environment variables are read by Large tldw fixture:

name|description
---|---
